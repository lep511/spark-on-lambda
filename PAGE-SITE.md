# The Rust Rand Book
This is the extended documentation for Rust's Random number library.

This book contains:

* Quick start
* An overview of crates, features and portability
* The Users' Guide
* Updating guides
* Contributor's guide

Outside this book, you may want:
* API reference for the latest release
* API reference for the master branch
* The Rand repository
* The Book source
